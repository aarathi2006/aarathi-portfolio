Healthcare Platform

Prototype built for a recruitment assignment

An AI-native platform for patient access and hospital operations. A patient describes a concern in a chat, and the assistant points them to the right doctor at the right hospital and books the visit. Around that sits a set of role-based dashboards, so each kind of user sees only what they need.

This is a working demo, not a production system. I built it to show how I structure a product with several user roles, data separation between hospitals, and an AI layer on top.
